# Core AI project instructions

## Visual quality is part of every change

Use the existing typography, spacing, color, and density tokens. Check alignment,
baseline, field and button sizes, wrapping, focus indicators, and local gaps in
every affected view. Make the current step, next action, and result easy to find.
Keep advanced controls reachable and preserve existing workflows.

For visible changes, check the complete flow at desktop and narrow pane widths,
including loading, empty, error, and completed states when relevant. Run the
frontend build and tests before publishing.
